# try_1

## 项目简介

这里保存个人学习笔记与教材，按学科归档。每个学科目录包含对应的 Markdown、网页、图片及已有的导出文件；笔记生成模板统一留在工作区根目录。

## 目录结构

```text
do_1/
├── README.md
├── 笔记生成模板.md
├── 笔记生成模板_旧版备份.md
├── 模电/
│   ├── 模电.md
│   ├── 模电第三章_手写思路提取.md
│   ├── 模电第三章_手写笔记对应表.md
│   ├── 模电第三章_轻量版.md
│   ├── 模电第三章_轻量版.html
│   ├── 模电第三章_轻量版.pdf
│   ├── 模电第三章_轻量版_配套/
│   ├── web-notes/
│   ├── output/    # 完整版、分析报告与已有导出文件
│   └── tmp/       # 原有材料处理、导出与检查的临时文件
├── 电路基础/
│   ├── 电路基础.md
│   └── web-notes/
└── 复变函数/
    ├── 复变函数.md
    └── web-notes/
```

## 阅读入口

| 学科 | Markdown | 网页 |
| --- | --- | --- |
| 模电 | [完整版](模电/模电.md) · [第三章轻量版](模电/模电第三章_轻量版.md) | [完整版](模电/web-notes/analog.html) · [轻量版](模电/模电第三章_轻量版.html) |
| 电路基础 | [笔记](电路基础/电路基础.md) | [网页版](电路基础/web-notes/circuits.html) |
| 复变函数 | [笔记](复变函数/复变函数.md) | [网页版](复变函数/web-notes/index.html) |

网页可直接从本地打开。各学科保留自己的网页资源；移动或备份时请一并保留对应学科目录。模电轻量版的 PDF 与配套回查页也位于模电目录中。

更新完整版网页时，在对应学科的 `web-notes` 目录运行 `同步笔记.ps1`；脚本只同步当前学科的 Markdown。具体操作见各学科目录中的网页版说明。
