#### ⑤ BJT 放大的内部工作原理

**定位**：以原稿 NPN 放大状态图为背景，把结构、偏置和载流子过程连起来。

**我的理解｜AI提炼**：

1. 发射结正偏，电子从发射区注入基区；发射区与基区的掺杂差别，联系到电子注入与反向空穴注入的相对大小。
2. 注入后形成浓度差，电子在基区边扩散边复合；基区薄、掺杂低，原稿据此解释“大部分穿过、少部分复合”，并把补充空穴联系到基极电流。
3. 集电结反偏，收集扩散过来的电子；最后归纳 NPN 中发射区发出、经过基区、被集电区接收的电子过程为主，其余为次。

**关键理解｜AI提炼**：三个区域的作用串成载流子的发射、扩散／复合、收集过程；原稿同时记录两种载流子参与导电。

**待核对**：原稿“发射结浓度”的用词、反向漏电流的分量归属及被忽略项见 [T04](模电第三章_手写笔记对应表.md#t04)。本版不展开未核准的分量公式。

#### ⑥ BJT 的电流关系

**定位**：电流守恒、两回路的控制描述，以及分配／放大关系系数。

**原稿起点**：在 NPN 图所标的 $I_B,I_C$ 流入、$I_E$ 流出方向下，由 KCL 写出 $I_E=I_B+I_C$。

**我的理解｜AI提炼**：习惯说“$i_B$ 控制 $i_C$” → 原稿追问这种说法的含义 → 把电路拆看为 $U_{BB}\to R_B\to B-E$ 与 $U_{CC}\to R_C\to C-E$ 两回路 → 比较两回路的影响和供能 → 将三电流看成同一整体，用电流间的控制说法表达回路间的控制。

**原话**：“为了方便，用 $i_B$ 控制 $i_C$ 来代替 B 回路控制 C 回路”。

原稿这里把实际控制归于 **$U_{BB}$**；轻量版保留这个认识，不用后补的另一套解释替换。随后采用 $i_C=\beta i_B$ 的固定比例，作出“只有 1 个独立电流变量”的判断，再插入三种连接。

<a id="bjt-current-coefficients"></a>

**我的理解｜AI提炼：α、β。** 在三种连接之后，原稿回到“分配关系／放大关系系数”，把系数联系到扩散、复合与器件内部结构。β 的蓝笔原话是：“描述了基区中非平衡少子的扩散和复合的比例。”

**待核对**：$U_{CC}$ 几乎不影响三电流、固定 β、独立电流判断所用的模型条件见 [T05](模电第三章_手写笔记对应表.md#t05)；系数定义、漏电修正式与记号层级见 [T06](模电第三章_手写笔记对应表.md#t06)。这些是原稿的阶段判断；α 范围末位也仍待辨认。

[回查两回路原话：手写1/5](模电第三章_手写思路提取.md#raw-hand1-5)；[独立电流判断：1/6页首](模电第三章_手写思路提取.md#raw-hand1-6-current)；[系数与公式：1/7](模电第三章_手写思路提取.md#raw-hand1-7-coefficients)。

### 5. 进阶电路的组成与工作原理

**定位**：分压式电流负反馈偏置电路。原稿自己的理解框架是：**原因／背景 → 原理 → [分析与计算](#amp-6-advanced) → [设计与条件](#amp-5-design)**。计算按知识归属放在第6项，阅读原稿路线时算完再回到条件。

**我的理解｜AI提炼：背景。** 固定偏置讨论完后，为稳定 Q 点引入另一电路；以温度对工作状态的影响说明为什么需要维稳。

**我的理解｜AI提炼：原理。** 分压使 $V_B$ 近似保持不变；原稿据此写出反馈链：

$$
i_C\uparrow\ \to\ i_E\uparrow\ \to\ V_E=i_ER_E\uparrow
\ \to\ U_{BE}=V_B-V_E\downarrow\ \to\ i_C\text{ 降低}.
$$

这条链以原稿的“$V_B$ 不变”为比较前提；其成立条件仍须结合设计与近似核对。

**原话**：“负反馈的本质不是回到原处，而是使减小扰动，达到 new balance。”

**关键理解｜AI提炼**：原稿区分形成反馈量的 $i_E$ 与主要关注的输出电流 $i_C$；将稳定 $V_B$ 的作用称为“压舱石”。

**原话**：“而 $R_{B2}$ 使分压成立，使 $V_B$ 稳定 → 此为压舱石。”

**尚未解决**：原稿还推到“$I_E$ 稳则其他量也稳”，并从“$V_B$ 稳”推到“$i_B$ 很小、可取零”。这些推论不随比喻一起当作已核准结论；见 [T15](模电第三章_手写笔记对应表.md#t15)。温升箭头固定了哪些量、“增加了 $U_E$”所指为何，分别见 [T14](模电第三章_手写笔记对应表.md#t14)、[T16](模电第三章_手写笔记对应表.md#t16)。

### 6. 直流分析方法

**定位**：基本电路与进阶电路两支。进入方法前，原稿先用以下目标区分静态与动态：

| 分析对象 | 原稿记录的计算目标 |
| --- | --- |
| 静态：直流工作状态 | $I_{BQ},I_{CQ},U_{BEQ},U_{CEQ}$ |
| 动态：交流信号及其响应 | $A_u,R_i,R_o$ 等性能参数 |

直流／交流通路都有定义，但“画法”未填。[回查手写2/3的方法入口](模电第三章_手写思路提取.md#raw-hand2-3a)；角色理解接 [“搭戏台”](#amp-4)，交流分析位置见 [第7项](#amp-7)。

<a id="amp-6-basic"></a>

#### 基本电路

**我的理解｜AI提炼：图解法。** 元件的 $u,i$ 同时受自身特性和外电路约束 → 同时满足特性曲线与电路方程 → 两曲线交点对应目前状态 → 输入回路配输入特性求 $I_{BQ},U_{BEQ}$，输出回路配输出特性求 $I_{CQ},U_{CEQ}$。

**原话**：“交点即为目前状态。此即为该法的思路、原理。”

**原稿估算式·待核对**：这是另一种并列方法，原稿主要记了结果，没有记录由图解法逐步推到估算法的过程。以下保留固定偏置原式，忽略压降、采用放大关系及状态校验的条件仍见 [T13](模电第三章_手写笔记对应表.md#t13)，不能无条件套用。

$$
\begin{aligned}
I_{BQ}&=\frac{U_{CC}-U_{BEQ}}{R_B}\approx\frac{U_{CC}}{R_B},\\
I_{CQ}&=\beta I_{BQ},\qquad
U_{CEQ}=U_{CC}-I_{CQ}R_C.
\end{aligned}
$$

原稿另取 $U_{BEQ}=U_{BE(\mathrm{on})}$。

[回查图解思路：手写2/3](模电第三章_手写思路提取.md#raw-hand2-3b)；[估算式：2/4上半](模电第三章_手写思路提取.md#raw-hand2-4a)。

<a id="amp-6-advanced"></a>

#### 进阶电路

**我的理解｜AI提炼**：先有 [稳偏背景与反馈原理](#amp-5)，再分压求 $V_{BQ}$ → 据基极电位和发射结压降求 $I_{EQ}$ → 用 α 关系求 $I_{CQ}$ → 求 $U_{CEQ}$，另列 $I_{BQ}$。原稿有这条计算顺序，各近似没有逐步推导。

**原稿估算式·待核对**：沿用原稿近似号，不提升为一般式；分压、α 近似及设计条件需分别核对 [T17](模电第三章_手写笔记对应表.md#t17)。

$$
\begin{aligned}
V_{BQ}&\approx\frac{R_{B2}}{R_{B1}+R_{B2}}U_{CC},\\
I_{EQ}&\approx\frac{V_{BQ}-U_{BE(\mathrm{on})}}{R_E},\\
I_{CQ}&=\alpha I_{EQ}\approx I_{EQ},\\
U_{CEQ}&\approx U_{CC}-I_{CQ}(R_C+R_E),\qquad
I_{BQ}=\frac{I_{EQ}}{1+\beta}.
\end{aligned}
$$

算完回到 [第5项“设计与条件”](#amp-5-design)，接续原稿的理解顺序。
